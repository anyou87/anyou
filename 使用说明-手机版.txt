========================================
  连连看 - 50桌预测工具 手机版 (Android APK)
  使用与构建说明
========================================

【这是什么】
桌面版"50桌预测工具"的手机版。预测逻辑与桌面版完全一致
（同一个 core_logic.py，两种载体计算结果一字不差）：
  - 50桌策略投票 + 走势调权 + 连错分级（无观望，每把都给方向）
  - 庄闲多数列：多数庄/闲显示红/蓝，与开奖不符变灰，平票绿色
  - 待开行黄色闪烁，提醒当前推荐
  - 表格可横竖滚动，按钮大、适合手机操作

----------------------------------------
【文件夹内容】
  main.py          手机版程序（Kivy UI）
  core_logic.py    预测核心逻辑（与桌面版共用，不要改动核心公式）
  msyh.ttc         中文字体（微软雅黑，保证中文正常显示）
  icon.png         安卓应用图标（512x512）
  buildozer.spec   APK 打包配置
  .github/workflows/build-apk.yml  GitHub 云端自动打包配置

----------------------------------------
【如何得到 APK 安装包（免费云端构建）】
Windows 电脑无法直接打包安卓 APK（需要 Linux 工具链），
用 GitHub 免费云端构建最省事，全程 4 步：

第1步：注册 GitHub 账号
  打开 https://github.com ，注册并登录（免费）。

第2步：新建仓库（仓库 = 一个云文件夹）
  点右上角 "+" → New repository
  名字随意，例如 lianliankan，选择 Public（公开），Create 创建。

第3步：把本文件夹所有内容上传进仓库
  进入仓库页面 → Add file → Upload files →
  把"手机版APK"文件夹里的【所有文件】拖进去
  （main.py、core_logic.py、msyh.ttc、icon.png、buildozer.spec、
   还有 .github 文件夹——注意上传时要保留 .github 这个文件夹结构）
  → Commit changes 提交。

第4步：触发构建并下载 APK
  构建会自动开始，也可以手动：
  仓库页面 → Actions 标签 → 左侧 "Build APK" → 右侧 "Run workflow"
  → 等 10~25 分钟（第一次构建要下载编译工具，较慢，以后会快）
  → 构建完成后点进本次运行记录，最下方 Artifacts 里
    下载 lianliankan-apk.zip → 解压得到 连连看-0.1-arm64-v8a_armeabi-v7a.apk

----------------------------------------
【安装到手机】
  1. 把 .apk 文件传到手机（微信/QQ 文件传输、数据线都行）
  2. 手机上点开该文件 → 系统提示"未知来源应用" → 允许安装
  3. 安装完成后桌面出现"连连看"图标（金色"连"字），打开即用

----------------------------------------
【常见问题】
  Q: 构建失败怎么办？
  A: 99% 是网络/工具链下载问题，直接在仓库 Actions 页点
     "Run workflow" 重跑一次即可；连续失败可把红色错误信息发给我。

  Q: 手机打不开 / 闪退？
  A: 最低支持安卓 5.0。如果闪退，告诉我手机型号和安卓版本。

  Q: 以后修改了桌面版逻辑，手机版怎么同步？
  A: 只改桌面版 + core_logic.py 两份文件，改动相同内容；
     然后把新 core_logic.py 上传到 GitHub 仓库 → Actions 自动重新打包。
